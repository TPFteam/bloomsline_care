## Concept 1: "The Week" (Visual Timeline)

**One slide. No words needed.**

```
┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│  Mon    Tue    Wed    Thu    Fri    Sat    Sun                    │
│   │      │      │      │      │      │      │                     │
│   ○──────○──────○──────●──────○──────○──────○                     │
│                       ↑                                            │
│                   Therapy                                          │
│                   (1 hour)                                         │
│                                                                    │
│   ○ = Life happening (no support)                                 │
│   ● = Therapy session                                             │
│                                                                    │
│                    "Where does growth actually happen?"            │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

**Presenter says:** "This is a week. One dot is different. That's therapy. What about the other 167 hours?"

## Concept 3: "The Loop" (Most Relatable)

**The cycle everyone knows but doesn't talk about**

```
┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│                         ┌─────────┐                                │
│                    ┌───►│ Feel bad │                               │
│                    │    └────┬────┘                                │
│                    │         │                                     │
│                    │         ▼                                     │
│              ┌─────┴───┐  ┌──────────────┐                        │
│              │ Give up │  │ Download app │                        │
│              └─────────┘  └──────┬───────┘                        │
│                    ▲             │                                 │
│                    │             ▼                                 │
│                    │    ┌────────────────┐                        │
│                    │    │ Use it twice   │                        │
│                    │    └───────┬────────┘                        │
│                    │            │                                  │
│                    │            ▼                                  │
│                    │    ┌────────────────┐                        │
│                    └────┤ Feel guilty    │                        │
│                         └────────────────┘                        │
│                                                                    │
│              "Sound familiar? You're not the problem."            │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘
```

**This is powerful because:** Everyone has done this. It's not accusatory—it says "you're not the problem, the tools are."

## My Recommendation: Combine Concepts

**Slide 1 (The Math):** 168 → 1 → 167

**Slide 2 (The Loop):** The download-use-quit cycle

**Slide 3 (The Texts):** Moments that go uncaptured

**Transition:** "What if there was somewhere for all of this to go?"

---

## Why These Work

| Traditional Problem Slide | Our Approach |
|--------------------------|--------------|
| "Mental health is a $XX billion problem" | Shows the human experience |
| "X% of people struggle with..." | Makes viewer feel seen |
| Bullet points of pain | Visual storytelling |
| Statistics | Emotion first, data as support |
| Tells you there's a problem | Makes you feel the problem |

**The goal:** By the time you show the solution, the viewer is already nodding, thinking "yes, I need this" or "yes, my clients need this."

---

## Tone

- **Not clinical** — human
- **Not accusatory** — empathetic
- **Not dramatic** — honest
- **Not salesy** — authentic

The problem slide should feel like a friend describing something you both understand, not a salesperson convincing you something is broken.
